The cloud was a detour.

For twenty years the industry convinced you that your data, your tools and your intelligence belonged on someone else's computer. They were wrong.

A used workstation with a $400 graphics card can now run a capable language model with a 128,000-token context — a whole book in one breath — at reading speed, for the cost of the electricity. You don't need their cloud. You need an operating system worthy of your machine.

"The computer for the rest of us didn't need to be simpler.
It needed to be yours."

ScrollOS is seven applications — Dream, Discover, Unwind, Create, Connect, Produce, Grow — organized around how you live, not how software companies sell. Each tool is a single HTML file. Each one runs offline. Each one talks to a model running on your own hardware, and to nothing else.

No API keys. No rate limits. No monthly bill. No data leaving your house. It's being built in the open, here on The Watch's Tech desk: the first eight tools are below, and the rest land as they're made.

This is the iMac moment for artificial intelligence.

What fits in your memory

Drag to your card's VRAM, or the memory a unified-memory machine gives the GPU. The model's weights have to fit, plus a cache that grows with the context window — that's the "128K context" trap. Rough numbers; the installer's 8-bit cache halves the context cost.

24GB for the model

Open weights, long context, all in Ollama's library. Mixture-of-experts models (the "A3B/A4B" ones) run a fraction of their parameters per token, which is why they fly on modest cards.

Install it in one script

Ubuntu 24.04 on the machine you built. Read the script first — it's short and commented — then run it. It installs the NVIDIA driver and Ollama, tells Ollama to accept web pages, pulls the model, downloads the Scrolls to ~/scrollos, serves them at localhost:8080, and sets up a nightly backup. Add --kiosk and the machine boots straight into the ScrollOS desktop.

# on the new machine
curl -fsSL https://bboldt86.github.io/lanscape-navigator/news/tech/scrollos/install.sh -o install.sh
less install.sh                      # read it
bash install.sh --kiosk              # or without --kiosk for a plain install
# a different model: SCROLLOS_MODEL=gemma4:26b bash install.sh
Download install.shRead it

Assemble, then Ubuntu

Card in the top x16 slot, both power leads on (the P40 takes an EPS-8, not a PCIe-8 — the adapter in the parts list), the fan shroud facing a case fan. Install Ubuntu 24.04 Desktop from a USB stick, with the third-party drivers box ticked.

Driver and Ollama

The script runs ubuntu-drivers install and Ollama's own installer. After the first reboot, nvidia-smi should show the card and ollama ps should answer. If the card shows in lspci but not in nvidia-smi, pick the driver in Software & Updates › Additional Drivers.

Open the door for web pages

The one line that makes ScrollOS possible: OLLAMA_ORIGINS=* in Ollama's systemd override. Without it, a page in a browser can't call the model. The script also turns on flash attention and an 8-bit KV cache so more context fits.

Pull a model, test it honestly

ollama pull gpt-oss:20b is 14 GB; go make coffee. Then open AI Lab › Machine › Run the test. That's your real tokens per second, and whether the whole model is on the GPU (100%) or spilling into RAM.

Live with it

The desktop is http://localhost:8080/scrollos.html. ⌘K focuses the prompt bar. Each tool has Export; the nightly backup in ~/scrollos/backups catches the rest. To update the Scrolls, re-run the script — your data isn't in the files.

A Mac with Apple Silicon is already a unified-memory machine. Install Ollama from ollama.com or Homebrew, then:

brew install ollama
launchctl setenv OLLAMA_ORIGINS "*"     # survives until you log out; put it in a LaunchAgent to keep it
brew services restart ollama
ollama pull gpt-oss:20b             # 16 GB Macs: fine. 8 GB: use llama3.1:8b

Install Ollama from ollama.com, then in PowerShell:

setx OLLAMA_ORIGINS "*"              # then quit Ollama from the tray and start it again
ollama pull gpt-oss:20b

No new hardware: whatever computer you're on, if it has 16 GB of memory it can run the small model and every tool here. Install Ollama, allow web pages, pull llama3.1:8b (or gpt-oss:20b on 16 GB+), and reload this page — the status line at the top goes green.

The architecture
Five layers, zero cloud.
The browser is the operating system. The model is the intelligence. The HTML files are the applications.
ApplicationLayer 5 · you see this
The Scrolls: single-file HTML tools in a browser (kiosk mode on the appliance). Each one has a prompt interface and calls the model with fetch('http://localhost:11434/api/chat'). No other network calls.
AI runtimeLayer 4 · inference
Ollama (llama.cpp underneath) as a systemd service on localhost:11434. Streams tokens, takes a system prompt per Scroll, keeps the model warm. Swappable for any server that speaks the same API.
ModelLayer 3 · weights
An open mixture-of-experts model in 4-bit GGUF with a 128K context — gpt-oss:20b by default. A few of its experts fire per token, which is why a 2016 card keeps up. Swap it with one command.
DataLayer 2 · storage
Each tool keeps its data in the browser's own storage, exports JSON, and never phones home. The installer backs that storage up nightly to ~/scrollos/backups. Disk encryption is one checkbox in the Ubuntu installer.
HardwareLayer 1 · metal
Ubuntu 24.04. A GPU with 16–24 GB, or a unified-memory box. The CPU runs the OS, the browser and the tools while the GPU is left alone with the model.

When it says no

Three causes, in order of likelihood:

Ollama isn't running

ollama ps in a terminal. On Linux: systemctl status ollama. On a Mac or PC, the app's icon should be in the menu bar or tray.

It's running but won't talk to web pages

Out of the box Ollama only answers pages served from localhost and files opened from disk. For a page on The Watch (https://bboldt86.github.io), set OLLAMA_ORIGINS — see the install tabs above — and restart Ollama. * allows any page in any browser on your machine; the specific origin is tighter.

The browser is Safari

Safari blocks a secure page from reaching an insecure local address. Download the tool and open the file, or use Chrome, Edge or Firefox for the hosted version.

05 · Honest notes
What's real, what's next.

Is "10 tokens a second" the number?

It was the conservative promise in the original vision, for a dense model on the P40. Mixture-of-experts models changed that: public benchmarks put gpt-oss:20b at tens of tokens a second on the same card, and over a hundred on an RTX 3090. Treat every number on this page as a class estimate and the AI Lab's speed test as the truth for your box.

What does The Watch see?

Nothing you type. These pages are static files on GitHub Pages; the tools call your own address and no other. There's no analytics in the tools. The only thing that leaves your machine is the request to download the files.

Where's the rest of the 63?

Built in the open, one at a time, and published here as each one is ready. The Scrolls map above shows what already exists elsewhere on The Watch — the news desks, Weekender, Finds, Vision, Film Room, the hobby tools — and what's still to come. The source for everything here is in the lanscape-navigator repo.

Can I use a different model server?

Anything that speaks Ollama's /api/chat and /api/tags works — point the address at it in any tool's settings. LM Studio, llama.cpp's server and others expose compatible endpoints or an OpenAI-style one; an adapter for the latter is on the list.

Does the P40 have a future?

Short-to-medium. NVIDIA's newest CUDA releases no longer target its generation, and Ollama will eventually follow. It's the cheapest 24 GB you can buy today and will keep running the builds that exist; just don't expect it to run what ships in 2028. The 3090 and the unified-memory boxes are the longer bets.

Why single HTML files?

Because a file you can copy, open, read and keep is the most durable software there is. No build step, no server, no account, no dependency that goes away. It's how everything on The Watch is made, and it's how ScrollOS stays yours.
