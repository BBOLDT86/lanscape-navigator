How it works

Pair two devices in a minute.

  1. Open itOpen any product here, or download the file and double-click it. It works on its own, offline too.
  2. Show your codeTap Share. Your six-letter code is this browser's name; send it, or show the QR.
  3. ConnectThe other person types your code (or scans). The first time, you let their device in.
  4. Forget about itFrom then on the two devices find each other whenever both are open. Everything stays in your browsers; back up as a file or a link.
